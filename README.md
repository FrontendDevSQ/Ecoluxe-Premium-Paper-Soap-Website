# Ecoluxe — Premium Paper Soap Website 🌿

> A modern, multi-page e-commerce website for a premium paper soap brand - featuring smooth AOS scroll animations, product showcase, and a fully responsive layout.

## ✨ Features

- 🏠 **Multi-Page Structure** — Home, About, Products, and Contact pages
- 🎬 **AOS Animations** — smooth fade, slide, and zoom effects on scroll
- 🛒 **Product Showcase** — elegant product cards with wishlist and basket UI
- 🎨 **Modern UI** — clean typography, hero banner with overlay text

- Multi-page architecture with shared navbar and footer components
- Hero section with background image, overlay, and animated typography

## 🚀 Run locally

```bash
# Clone the repo
git clone https://github.com/FrontendDevSQ/ecoluxe.git

# Open in browser
cd ecoluxe
open index.html
```
No installs. No build step. Just open and view.
